# docs/releases/

Handoff/release-notes drafts composed by the Lab 26
`enterprise-sdlc-workbench` canvas's `release-composer` canvas land here
when a learner explicitly chooses to save one (the "save" action is
distinct from "publish" -- see the extension's README for details).

Nothing is written to this directory automatically; it starts empty aside
from this placeholder, which keeps the directory tracked in git.
