# ContosoUniversity (lab workspace)

This is your lab workspace — a miniature TypeScript edition of the
ContosoUniversity app used throughout the Everything GitHub Copilot labs.

Everything you change here stays inside the sandbox. Use **Reset workspace**
in Lab Studio to restore it to this state at any time.

| Where       | What                                                 |
| ----------- | ---------------------------------------------------- |
| `.github/`  | Copilot configuration: instructions, agents, skills  |
| `.copilot/` | MCP server config and the lessons log                |
| `src/`      | The application code Copilot reads and reasons about |
| `tests/`    | Vitest unit tests                                    |
